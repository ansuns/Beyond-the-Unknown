# Cocos Creator client

This directory is the designated root for the WeChat Mini Game client.

## Planned layout

```text
client/
├── assets/                 # Cocos scenes, prefabs, scripts, resources
├── settings/               # Cocos Creator project settings
├── extensions/             # Project-local editor extensions (if needed)

└── README.md
```

Initialize the actual project with the agreed Cocos Creator 3.x version when the client vertical slice begins. Do not commit generated editor caches, build output, local credentials, or placeholder project metadata.
