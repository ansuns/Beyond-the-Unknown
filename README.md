# 无界之外 · Beyond the Unknown

一款面向微信小游戏的原创 Q 版奇幻探索解谜游戏。本仓库为《无界之外》游戏设计文档（GDD）的源码。

## 文档结构

- [GDD 总览](无界之外_GDD_总览.md)：全局规则（G-001~G-017）、18 章目录与状态、统一文档规范、开发优先级。
- 第 1–18 章：产品定义与版本范围、核心玩法循环、玩家角色系统、地图与场景系统、多人共享系统、探索关卡系统、世界法则系统、法则组合与解谜系统、交互与机关系统、探索发现与收藏系统、任务结算与进度系统、奖励与成就系统、排行榜与赛季系统、轻社交系统、商业化与广告系统、UI 与交互界面规范、技术架构与数据规范、美术资源音效与测试验收规范。

## 文档状态

全部章节为 GDD V0.1 初稿，待制作人 / 程序 / 美术联调确认数值（半径、冷却、时长、频率、帧率、内存等）与引擎选型（Cocos Creator 3.x 待最终确认）。
