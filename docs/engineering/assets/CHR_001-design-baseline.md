# CHR_001 设计基准（基准图依据）

- 日期：2026-10-31
- 依据：GDD V0.2 第 3 章（角色定位与交付清单）、第 18 章 18.1（美术风格基线）
- 用途：作为 `CHR_001_MODEL` / `CHR_001_PORTRAIT` / `CHR_001_PREVIEW` 的图生图参考图，锁定角色身份

## 1. GDD 给出的硬约束

| 约束 | 出处 | 对设计的含义 |
|---|---|---|
| 原创 Q 版奇幻风格 | 18 章设计基线 1 | 头身比约 1:3，圆润、亲和，不写实 |
| 12 个预设角色，差异仅在模型/配色/头像/动作/展示特效 | 3.0 设计基线 2–4 | 外观不承载数值，因此可以放心做强识别度 |
| 外观不得影响移动、碰撞、发现、积分 | 3.0 设计基线 4 | 体型不能夸张到与碰撞半径脱节 |
| 脚底接地点作为 Sprite 锚点 | P0 交付单 §2.3 | 站立姿态，双脚清晰分离，脚尖朝画面下方 |
| 等距投影、按纵深排序、可被遮挡 | P0 交付单 §2.2 | 不要大翅膀、长飘带、拖地披风，否则遮挡排序会破 |
| 8 方向 IDLE / MOVE | 3 章 3.5 | 正面 3/4 视角最利于推导其余方向 |

GDD 未规定 CHR_001 的具体配色与道具，以下为本项目自定的设计基准。

## 2. 角色设定

**身份**：无界之地的年轻「探界者」——不带武器，靠观察与试探解谜，与第 7 章三法则（回声/注视/逆转）的玩法定位一致。

| 项 | 取值 | 理由 |
|---|---|---|
| 头身比 | 1:3，头略大 | Q 版奇幻基线 |
| 主色 | 青绿 (`#3F7F7A` 系) | 与关卡青灰石地、冷调雾光同族，不抢机关 |
| 辅色 | 琥珀 (`#C98B3E` 系) | 呼应机关暖光与 UI 主色，形成全局对比 |
| 中性色 | 亚麻白偏米 (`#E8DFC9`)，不用纯白 | 纯白在色键与暗背景上都易糊边 |
| 头发 | 深棕近黑，短碎发 | 与浅色外套形成剪影对比 |
| 眼睛 | 青蓝，大而圆 | Q 版识别点 |
| 道具 | 单肩皮革挎包 + 腰间小提灯 | 探险者身份；体量小，不影响遮挡排序 |
| 剪影 | 上宽下窄的短斗篷 + 短靴 | 等距下轮廓清楚，不与地面装饰混杂 |
| 禁用 | 武器、披风拖地、翅膀、长飘带、背面大背包 | 会破坏脚底锚点与纵深排序 |

## 3. 交付派生关系

```
CHR_001_BASE（本基准图，全身直立参考）
  ├── CHR_001_MODEL        透明背景、脚底贴底边、单帧直立
  ├── CHR_001_PORTRAIT     半身、透明背景
  └── CHR_001_PREVIEW      角色选择展示姿态、透明背景
```

派生一律用图生图并保持高保真，不再独立文生图——独立生成会导致披风颜色、瞳色、肤色漂移（已在
`asset-generation-backend-findings.md` 第 2.3 节记录实测差异）。

## 4. 验收前置

基准图本身不是交付资源，只作为参考。派生资源进入 manifest 时仍需登记
`source_type=GENERATED_WITH_REVIEW` 与生成记录；`CHR_001_ANIMATION_SET` 的 8 方向帧无法由单张
基准图推导，仍需单独制作，不能因为有了基准图就标记完成。
